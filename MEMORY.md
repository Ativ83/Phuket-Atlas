# Phuket Atlas — краткая память проекта

## Правило
Сначала `AGENTS.md` и этот файл, затем только документы и фрагменты кода, относящиеся к задаче. Фиксировать существенные изменения, не дублировать Git-историю.

## Назначение
Интерактивный атлас Пхукета и каталог собственных предложений по недвижимости; есть отдельная инфраструктура для защищённой версии. Публичный GitHub Pages не считать приватным.

## Карта проекта (основные файлы)
- `index.html` — главная страница атласа и интерфейс.
- `app.js` — логика основного приложения; точные имена функций проверять в коде.
- `broker-ai.js` — клиентская логика AI-помощника; перед изменением изучить зависимости.
- `editor.html` — редактор.
- `3d-preview.html` — предварительный просмотр.
- `data/locations.json` — география, районы и записи объектов.
- `data/district-narrations-ru.json` — русскоязычные тексты районов для озвучивания.
- `data/SCHEMA.md` — правила добавления объектов и координат.
- `presentations/` — презентации объектов; не публиковать конфиденциальные файлы.
- `assets/` — изображения и другие ресурсы.
- `scripts/` — сборка, обложки проектов и генерация звуковых файлов.
- `ai-worker/src/index.js` — Cloudflare Worker закрытой версии.
- `ai-worker/wrangler.toml` — конфигурация Worker.
- `.github/workflows/` — автоматизация публикаций, озвучки и проверок.
- `README.md` и `ai-worker/README.md` — обзор и инструкция по безопасному развёртыванию.

Подробная карта: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Зафиксированные решения
- Согласованные настройки озвучки районов не менять без запроса.
- Пользователь подтвердил «версию 2» как правильный эталон произношения; особенно название «Патонг». Это пользовательское подтверждение, а не автоматическая проверка текущих файлов.
- Публичную версию не отключать до успешной проверки защищённой, если пользователь не попросил иначе.
- В Atlas не подключать Bitrix24 без отдельного запроса.
- Не публиковать закрытые агентские материалы и секреты.

Полный реестр: [docs/DECISIONS.md](docs/DECISIONS.md).

## Как продолжать
1. Определи затронутые файлы по этой карте.
2. Прочитай только нужные источники и релевантные записи в `docs/`.
3. Внеси минимальную правку, проверь и кратко отчитайся.
4. Обнови документ с решением или ошибкой, только если появилась существенная новая информация.

Текущая передача контекста: [docs/CURRENT_TASK.md](docs/CURRENT_TASK.md).

## Atlas v2 — экономный рабочий процесс
- В `AGENTS.md` утверждён облегчённый протокол по принципам ECC: контекст по требованию, повторное использование решений, проверки по риску, необязательные субагенты, контроль diff и секретов.
- Не устанавливать полный ECC и не запускать сторонние хуки/агентов автоматически. Действующие правила и эталон озвучки сохраняются.
