# Реестр ошибок и проверенных исправлений

Записывай только воспроизводимые проблемы и проверенные исправления. Формат: дата, симптом, затронутые файлы, причина (если установлена), исправление, как проверить, статус.

## Исторический контекст: произношение районов
- Симптом: некорректное произношение названий районов, включая «Патонг».
- Пользователь подтвердил результат «версия 2» как правильный.
- Точный коммит/аудиофайл и механизм исправления здесь **не установлены**; при следующей аудиозадаче сначала найти и зафиксировать их.
- Статус: решение согласовано пользователем; актуальную реализацию в репозитории не перепроверяли.
