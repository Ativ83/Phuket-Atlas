# Добавление только собственных объектов

Файл `data/locations.json` содержит районы как ориентиры, но **не чужие объявления**. Добавлять объекты следует только в массив `objects` нужного района.

Пример записи:
```json
{
  "name": "Название из презентации",
  "type": "Кондоминиум",
  "description": "Подтверждённое описание",
  "lat": 8.001,
  "lon": 98.301,
  "pdf": "presentations/project-name.pdf"
}
```

Если точное расположение объекта неизвестно, не добавляйте `lat` и `lon` — объект появится в карточке района, но не получит ложную точку на карте.

PDF-путь указывает на документ внутри папки `presentations/`. **Публичный GitHub Pages означает, что любой посетитель с адресом сможет видеть презентации и объекты.** Публикуйте только материалы, на распространение которых есть разрешение.

Присылайте PDF в ChatGPT: на его основе можно обновлять соответствующий район, создавать объект и загружать разрешённую к публикации презентацию.
