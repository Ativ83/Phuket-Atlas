# Phuket Atlas

Личный интерактивный атлас объектов недвижимости на острове Пхукет. Карта — художественная схема для презентации, **не точная 3D-модель местности**.

В каталоге только собственные объекты брокера. Районы — ориентиры, а не чужие объявления.

## Добавление объекта

В data/locations.json у соответствующего района добавьте запись в objects, например:

```json
{"name":"Название проекта","type":"Кондоминиум","description":"Описание только из PDF","lat":7.999,"lon":98.299,"pdf":"presentations/project.pdf"}
```

PDF положите в папку presentations/. Если точные координаты неизвестны, поля lat и lon у объекта пропустите: карточка будет доступна в районе, но не появится неточная метка. Не публикуйте конфиденциальные PDF: GitHub Pages общедоступен.

Для публикации включите Settings → Pages → Source: GitHub Actions.
